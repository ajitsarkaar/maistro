# maistro skills

The skills bundled with [maistro](../../README.md), loaded into every Maistro and worker
session with `--plugin-dir`. Invoke user-started skills as `/maistro:<name>`.

These skills are original adaptations, for a multi-agent setting, of the engineering
workflow designed by Matt Pocock in [mattpocock/skills](https://github.com/mattpocock/skills)
(MIT). Credit for the underlying ideas is his.
